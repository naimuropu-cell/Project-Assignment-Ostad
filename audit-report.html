2. Defect Log & Technical Issues

BUG-01: Mixed Content Vulnerability (Insecure HTTP Assets on HTTPS)

Severity: Critical (P1)
Location: HTML <head> and Footer DOM across all pages

Description: Favicon links, Apple touch icons, and footer logo links are hardcoded to insecure http://yesbangladesh.net/... instead of https://.

<link rel="icon" href="http://yesbangladesh.net/wp-content/uploads/2026/06/Blue-and-Black-Flat-Illustrative-Business-Company-Logo.png"> <a href="http://Yesbangladesh.net"> <!-- Uppercase hostname & insecure protocol -->

Impact: Modern browsers flag Mixed Content warnings, degrading domain trust indicators and search engine rankings. The filename also exposes an unedited Canva template name.

Fix: Update WordPress General Settings to HTTPS, enforce HTTPS redirects, and rename favicon asset to favicon.png.

BUG-02: Broken Anchor Links on All Homepage Service Cards

Severity: High (P1)
Location: Homepage Core Services Grid (Section 3)

Description: All 6 "Learn More" links on the service cards link to #contact:

<a href="#contact" class="yes-service-link">Learn More ...</a>

Impact: There is no element with id="contact" on the homepage. Clicking "Learn More" produces a dead click, preventing prospective clients from discovering service specifics or contacting the team.

Fix: Point each service card to its respective subpage (/web-software/, /amazon-experts/, /u-s-company-formation/) or add an anchor contact section.

BUG-03: Telephone Field Formatted as type="number"

Severity: High (P2)
Location: /contract-application-form/ (WPForms Field 3)

Description: The contact phone number input uses HTML5 type="number" step="any" instead of type="tel".

Impact: Truncates leading zeros (e.g. Bangladeshi 0171... becomes 171...), allows mouse wheel scrolling to alter digits, allows scientific notation (1e10), and rejects international + signs.

Fix: Reconfigure the field in WPForms to a dedicated Phone Field (type="tel") with international dial code masking.

BUG-04: Footer Newsletter Validation & Honeypot Autofill Conflict

Severity: Medium (P3)
Location: Global Footer Newsletter Subscription Widget

Description: The subscription form has default placeholder name "New Form" and uses type="text" instead of type="email". Additionally, the anti-spam honeypot uses a visible label "Address" with a hidden input.

Impact: Allows users to submit invalid email strings. Password managers (Chrome, Bitwarden, 1Password) autofill the "Address" field, causing legitimate users to be falsely flagged as bots and blocked.

Fix: Switch input to type="email" with HTML5 validation and randomize honeypot field attributes.

3. What Is Missing (Critical Functional & SEO Gaps)

1. Dedicated "Book a Strategy Call" Funnel:

All CTA buttons promise a "Free Strategy Call", but route to a formal "Contract Application Form" demanding legal commitments. A low-friction 3-field booking form (Name, Phone/WhatsApp, Service Interest) or direct Calendly booking is completely missing.

2. Meta Descriptions & Search Snippets:

The site has zero <meta name="description"> tags. Search engines are forced to scrape random hero text, resulting in poor search snippet appearance and reduced Organic Click-Through Rate (CTR).

3. Open Graph (OG) & Social Cards:

Missing og:title, og:description, og:image, and twitter:card. When clients share links on WhatsApp, LinkedIn, or Facebook, no preview banner or branding appears.

4. Direct WhatsApp Floating Action Button (FAB):

In the Bangladeshi and diaspora markets, over 70% of business inquiries happen via WhatsApp. The website lacks an instant WhatsApp chat bubble, causing significant mobile conversion drop-off.

4. UI/UX, Typography & Performance Inconsistencies

A. Brand Identity & Typography Crisis

  • Homepage: Premium aesthetic utilizing modern Satoshi font, Royal Blue (#1B4FD8), and Gold accents (#FFC321).
  • Contract Application Page: Abruptly changes to Teal (#0f766e) and plain Arial (font-family: Arial, sans-serif !important;). The page looks like an entirely different website.

B. Excessive Logo Image Payload

  • The header and footer logo (yes-bd-logo-scaled.png) is loaded at 2560 × 640 pixels (>200 KB) for a display height of only 50px!
  • Recommendation: Replace with an SVG vector or optimized WebP under 15 KB to drastically improve mobile First Contentful Paint (FCP).

C. Tablet Viewport Layout Deficiency

  • Between 768px and 1024px, the CSS rule .yes-hero-visual { display: none; } abruptly hides the entire hero visual column (satisfaction badge, stat pills, cards), leaving an awkward white space.

5. Prioritized Remediation Roadmap

Phase 1: Immediate Hotfixes (Day 1 - 2)
  1. Update WordPress URL settings to force HTTPS and eliminate Mixed Content warnings.
  2. Fix the 6 dead #contact links on the homepage service cards to route to subpages.
  3. Change WPForms contact number input to type="tel".
  4. Add essential SEO Meta Descriptions and Open Graph preview tags.
Phase 2: UI/UX & Conversion Harmonization (Week 1)
  1. Unify styles: Remove hardcoded Arial/Teal on the contract page to match Satoshi/Royal Blue.
  2. Separate discovery leads from formal contract submissions with a streamlined consultation form.
  3. Deploy lightweight SVG vector logo.
Phase 3: Growth & Engagement (Week 2+)
  1. Integrate official floating WhatsApp widget for instant lead capture.
  2. Add verified founder photos and client portfolio case studies to strengthen social proof.
